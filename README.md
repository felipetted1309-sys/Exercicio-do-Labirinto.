# Exercício Algoritmos II:
Projeto desenvolvido durante o segundo período de faculdade.

## Linguagem: 
- C++.

- ### Sobre:
- Um jogo de labirinto em que o jogador deve encontrar a saída. O mapa pode ser girado quando o jogador está sobre uma alavanca,
- fazendo com que os blocos sofram ação da gravidade e podendo alterar os caminhos do labirinto. As portas abrem e fecham dependendo da rotação.

- #### Conteúdo
- Funções.
- Laços de repetição.
- Matrizes.
- Vetores.
- Estruturas condicionais.
- Entrada de dados pelo teclado.
- Rotação de matrizes.
